# Cómo colaborar

Si encuentras un problema, explica la versión del plugin, LliureX/Ubuntu, Java, Fiji/ImageJ, el modelo de microscopio y los pasos para reproducirlo. Indica qué esperabas y qué ocurrió. No publiques fotografías del alumnado ni registros con datos personales.

Para proponer un cambio, crea una rama o fork, separa la corrección de otros cambios y añade una prueba cuando el comportamiento pueda comprobarse sin hardware. Explica el motivo del cambio y sus límites. Ejecuta `make test IJ_JAR=/ruta/al/ij.jar` antes de enviarlo.

Mantén el estilo legible y comentarios que expliquen decisiones o restricciones reales, no que repitan cada instrucción. Los cambios de permisos o dependencias del sistema no deben introducirse como acciones del plugin: se coordinan con el empaquetador.

Se entiende que las contribuciones propuestas para este proyecto se ofrecen bajo la misma licencia MIT. Conserva la atribución existente y añade la que corresponda a tu contribución. No se solicita cesión de derechos exclusiva ni un contrato de soporte.

La existencia de Issues y Pull Requests no garantiza atención o aceptación. Véase MAINTENANCE.md. Los servicios solicitados a Robot-Edu requieren acuerdo comercial previo.
