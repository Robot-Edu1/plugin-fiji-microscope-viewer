Plugin independiente Microscopio Color para Fiji.

Fuentes Java y documentación bajo MIT, sin distribución de Fiji ni instalador del sistema. Captura RGB 1280×720, JPEG y MP4, con archivos por cuenta.

Los artefactos incluyen un JAR propio, tarball fuente y SHA256SUMS.txt. Las pruebas de datos son sintéticas; la validación del microscopio físico con LliureX sigue pendiente.

Robot-Edu no asume mantenimiento gratuito ni soporte continuado. Los trabajos solicitados requieren presupuesto y aceptación previa. LliureX y la comunidad pueden mantener el código conforme a MIT.
